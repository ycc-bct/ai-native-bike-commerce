「編輯塗裝」入口：三個提案

下面嵌的都是實際的客製車編輯頁（自由配色、選到 Type 4），可以直接點其他 Type 試。現在的入口是選到的卡片右上角一顆只有鉛筆圖示的圓鈕，文字要停在上面才會出現。

1 文字膠囊2 卡片底部操作列3 清單下方主按鈕

1文字膠囊

右上角只有鉛筆圖示的圓鈕，改成深色膠囊「✎ 編輯配色」，選到哪張卡就出現在哪張。改動最小，一眼看得出是按鈕。

載入中…

2卡片底部操作列

選到的卡片下緣多一條「✎ 調整這個配色 →」，整條都能點，跟卡片是一體的。最直覺，但選到的那一列卡片會變高一點。

載入中…

3清單下方主按鈕

卡片上不放按鈕，四張卡片下方放一顆全寬主按鈕「✎ 編輯 Type 4 的配色」，會跟著你選的版型改字，下面一行小字說明可以換哪些。流程最清楚：先選、再編輯。

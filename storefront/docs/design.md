## 2. RWD 原則（每一條都能檢查）

1. **元件不因螢幕變窄而換長相。** 圓角按鈕在 375px 還是圓角、圓形社群圖示還是圓形、卡片圓角同一個數字。變窄只能改排列、間距、顯示與否，不能改元件本身的形狀、字重、顏色。
2. **手機的字級來自第 4 節的表，不臨時發明。**
3. **能點的東西高度至少 40px。** 視覺比 40 小的控制項（色票、圓點、文字連結）加一個看不見、置中的 40px 點擊區（`::before`）；被 `clip-path` 裁切而加不了點擊區的（置頂的返回列），本體直接長到 40px。
4. **同一個 panel 裡的同類選項等高、平均分欄寬。** 兩個並排選項用 `repeat(2, minmax(0,1fr))`，不讓其中一個因字多而變高。
5. **空間不夠就收進選單，不縮點擊區。**
6. **置頂的東西在捲動時不跳動。** 返回列、標題、panel 標題以 `position:sticky` 疊在 header 下面，高度寫成變數，JS 量的高度與 CSS 一致。

## 3. 斷點

新做手機版的頁面用這四個斷點，不要另訂新的。卡片要看自己的寬度才能決定排列時（顧問面板打開、內容變窄），用 container query，不要多開視窗斷點。

| 寬度 | 用途 | 邊界 |
|---|---|---|
| ≤ 1023px | 雙欄改單欄捲動（客製車設定頁：預覽在上、選項在下、總價列固定底部）；平板與手機共用 | 不要在這裡改 header／footer |
| ≤ 900px | header 換成手機版（漢堡選單）；footer 改單欄 | 全站同一套，由 `header.js` 的 `data-mobile-nav` 開啟 |
| ≤ 767px | 手機專屬排列；大部分手機規則都放這裡 | |
| ≤ 370px | 只收 header 圖示間距（≤ 340px 時 header logo 縮成 72px，100px 放不下） | 不再收功能、不縮點擊區 |

### 返回與麵包屑

依頁面類型分兩種，外觀規則相同：

| 頁面類型 | 用法 | 例子 |
|---|---|---|
| 內容頁（列表、商品、介紹頁） | 麵包屑 `首頁 / 分類 / 目前頁` | 礫石列表頁、商品頁 |

- 深色照片上：連結 `rgba(255,255,255,.72)`、分隔線 `.45`、目前頁白色。

## 5. 中文斷行

不要讓一個字或半個詞單獨掉到下一行（例如「染」、「分層／遮罩」、「RRS 及／DCF」）。

- **先改寬度或字數**，讓它一行放得下。
- 放不下時，**用片語包住、整段換行**：把後半句包在 `display:inline-block` 的 span 裡，放得下就同一行，放不下就整段掉到下一行。
  ```html
  <p>選擇你的車系，探索特製樣板與經典塗裝，<span class="nb">打造專屬於你的騎乘風格。</span></p>
  ```
  ```css
  .nb { display: inline-block; }
  ```
- 手機上 `.nb` 也放不下，就改字數。
- `text-wrap: balance` 會在詞中間切開，中文不要用；`text-wrap: pretty` 可以當輔助，但不能取代上面的做法。

## 7. 間距、圓角、高度

**間距**
- 頁面左右留白：桌機 `var(--shell)` 置中，1440 寬時左右各 36px；手機一律 16px，不要另用 20 或 24。header 內圖示到邊、手機 panel 內距也是 16px。
- 區塊上下：88–96px。
- 標題 → 說明：10px。說明 → 內容：24–40px。
- 客製車：桌機 panel 內距 28px（設計系統），購物車抽屜用變數 `--gc-pad` 在 28／16 之間切換，不在各元素上寫死。
- 客製車：`8px` 是「緊貼」（步驟列到返回、角度點到選項面板）；`6px` 是卡片內文字群組的 gap（例如變速套件卡 `gs-body`）。

**圓角**（每個寬度都相同）
- 圓形的東西（社群圖示、角度點、背景色票、會員頭像）永遠是 50%／999px。
- 主要動作按鈕永遠是膠囊形（999px）：設定頁「下一步／加入購物車」、購物車「預約門市確認／前往結帳」與彈出小窗的「查看購物車／前往結帳」、結帳頁所有 `.btn`。
- 客製車：其他按鈕 8、卡片 10、說明卡 12、購物車浮層 14、panel 18。手機上的選項面板頂端 14px 圓角、底部 0。

**高度**
- header 64px，不隨寬度變；桌機選單字 14px，也不隨寬度變。
- 點擊區下限見原則 3；選單列是 48px。
- 主要動作按鈕：手機（≤ 767）最小高度 44px，平板以上 48px。
- 客製車設定頁置頂列：`--cfg-nav: 40px`（返回列）＋ `--cfg-title: 28px`（標題）。改了高度要同步改這兩個變數。

## 8. 陰影

### 單車去背圖的陰影（商品頁、客製介紹頁塗裝區）

兩層：整台車的柔和落影＋兩個輪胎各一團接地陰影。只用 drop-shadow 會像浮在空中。

```css
.bike img { filter: drop-shadow(0 18px 24px rgba(20,26,34,.16)); }
.bike::after {           /* 接地陰影，放在車子底緣 */
  content:""; position:absolute; left:0; right:0; bottom:-5%; height:10%; z-index:-1; filter:blur(3px);
  background:
    radial-gradient(closest-side, rgba(20,26,34,.30), rgba(20,26,34,.12) 50%, transparent) 4.85% 50% / 34% 100% no-repeat,
    radial-gradient(closest-side, rgba(20,26,34,.30), rgba(20,26,34,.12) 50%, transparent) 94.7% 50% / 34% 100% no-repeat;
}
```

- 先量出輪胎著地點（車子去背框寬度的百分比）。目前 15 張塗裝樣板都在 **20.2%／79.5%**。
- **注意**：`background-position` 的百分比不是橢圓中心。寬 W% 的橢圓要讓中心落在 C%，位置要寫 `(C − W/2) ÷ (100 − W) × 100%`。

### 卡片、浮層

`0 1px 2px rgba(20,26,34,.06), 0 6px 18px rgba(20,26,34,.08)`；聚焦或浮起時加深到 `0 2px 4px …/.05, 0 14px 32px …/.11`。

## 9. 動態

- 一般轉場 0.25–0.6 秒，`cubic-bezier(.16,1,.3,1)`。
- **切換內容用小幅位移＋淡化**（約 20px），不要整個畫面寬度飛入飛出。方向跟著選單方向。唯一例外是手機選單換頁（見第 10 節）。
- 同一組內換圖（例如換樣板）：0.25 秒交叉淡化。
- 聚焦某個物件時，其他物件淡到 50%。
- 一定要處理 `prefers-reduced-motion`：直接換、不位移。

## 10. 元件在手機上的決策

Header、Footer、購物車的改動一律改在共用檔（`storefront/js/header.js`、`footer.js`、`cart.js`），不為單一頁面複製一份改法，讓所有頁面一起變。

### Header（≤ 900）

- 左：漢堡（40×40，開啟後變 ✕）；中：logo 寬 100px；右：搜尋、購物車、會員、選車顧問。
- 我的最愛（愛心）**每個寬度**都不在 header 上，收進會員選單的「我的最愛」那一列，點了打開同一個抽屜。
- 購物車數字貼著圖示，離圖示右 8px、上 6px，桌機手機相同。手機的點擊框比圖示大，數字要對齊圖示，不是對齊點擊框。
- 漢堡選單（手機主選單抽屜）：從 header 下緣到畫面底部滿版、白底、不透明；不放搜尋與會員（header 上已有）；**列與列之間沒有分隔線**（參考 Aesop）。
- 子選單一律**換頁**（右滑進、左滑回），每頁第一列是「‹ 返回」；有分類主圖的放 16:9 圖卡（`gn-kv`），「看全部」不放在圖上，放在子分類最下面，用跟桌機下拉同樣的藍色連結（`#1F4FE0`、14px／600、列高 48px）。精品配件頁照 Apple 的寫法：灰色 14px 分類名，下面列項目。
- 換頁只用 transform／opacity，0.5s `cubic-bezier(.16,1,.3,1)`；目前所在頁不換色（「客製化」不變藍）。
- 鍵盤與讀屏：按鈕的名稱隨狀態在「開啟主選單／關閉主選單」之間切換，並更新 `aria-expanded`；按 Esc 關閉選單，焦點回到漢堡。

### Footer（≤ 900）

單欄，每個連結一列、高 40px；社群圖示維持圓形；logo 跟 header 同為寬 100px。各頁的 footer 必須逐項一致，桌機寬度也相同（左右對齊 header）；只有顧問面板打開、內容讓位時才變窄。

### 共用元件（≤ 767）

規則都在共用檔，頁面不要再寫一份；頁面只能因為自己有底部列，才調整比較列的 `bottom`。

| 元件 | 檔案 | 手機規則 |
|---|---|---|
| 顧問面板 | `css/advisor.css` | 從 header 下緣到畫面底部；按鈕 40px；輸入框 16px，iOS 才不會放大畫面；≤ 1023 蓋在內容上，內容不讓位（`body.adv-open` 的推擠規則只用在 ≥ 1024） |
| Tips | `css/tips.css` | 手機不放（≤ 767 隱藏）；平板保留，主選單打開時隱藏 |
| 我的最愛抽屜 | `css/favorites.css` | 內距 16px |
| 購物車小窗 | `js/cart.js` | 貼右 16px，不超出左緣 |
| 比較列 | `js/compare.js` | 滿版減左右 16px，已選車款在第二列左右滑 |
| 門市選擇 | `js/store-picker.js` | 清單列兩欄，電話在第二列；≤ 1023 選項 44px、輸入框 16px |

### 客製車：這兩頁在手機上要做到的事

使用者在手機上選一台車、一步步配到能加入購物車。畫面上永遠要看得到**現在在哪一步、車長什麼樣子、總價多少、下一步在哪**；其他東西都可以收起來，這四件不行。

### 客製車：介紹頁塗裝區（≤ 767）

色票放進弧線內，排在 PROPEL／DEFY 下方、TCR／TRINITY 之間，「用 TCR 開始客製」跟著上移。色票頂距弧線頂 77px；320 寬兩側較擠，放到 109px。

### 客製車：選車系／選車款（≤ 767）

- `pick-page` 上方 64px（header 高）；返回列置頂在 header 下方，跟 header 之間**沒有線或陰影**，背景與頁面同色、滿版（`box-shadow:0 0 0 100vmax` ＋ `clip-path`）。
- 返回列 `padding:0 0 12px`；頁面主標 `margin:16px 0 24px`。兩頁一致。

### 客製車：設定頁（≤ 767）

- 由上到下：返回列與標題（置頂，往下捲時一起收起）→ 車圖預覽 → 選項 panel → 底部固定的總價＋「下一步」。
- 步驟列併進 panel-head（`cfgPlaceIntro()` 把 `.intro` 搬進 `#panelHeader`），跟返回之間 8px；目前步驟名稱跟 panel 標題重複時，標題只留給螢幕閱讀器（`.step-dup`）。
- 步驟圓圈都有灰色外框，目前這步是深色外框。
- panel-head 內距 `16px 16px 0`；設定頁返回連結 margin、padding 都是 0，高度靠 `min-height:40px`。
- **「下一步」按鈕在手機與平板只寫「下一步」**，不寫下一步的名稱；最後一步是「加入購物車」，編輯時是「更新購物車」，從確認頁回來是「儲存並返回確認」。
- 漆面選項放在「漆面」標題下一行，兩個選項平均分欄寬。
- 配件選項卡：加價金額是圖片右上角的白色膠囊（12px）；不加價的不顯示標籤，也不留空位。配件圖統一放在標籤下方的同一塊區域（距上 36px、左右 16px、距下 12px），不論有沒有加價，大小都一樣，價格不能壓到圖；卡片比例固定 1.25，不被圖撐高。
- 切換步驟一律回到頁面頂端，面板位置固定，不因步驟不同而跳動。

### 客製車：車圖預覽（≤ 767）

- 換角度用**左右滑**；角度點只是位置指示，點了沒反應，平常隱藏，滑動後出現 1.5 秒。
- 背景切換是步驟列最右邊一顆 32px 圓形色票（目前背景），點一下直接換下一個背景（淺色 → 深色 → 山路），不展開選單。平板以上維持工具列裡的色票。
- 全車圖上下各留 16px；放大的局部圖上方 16px、下方貼齊選項 panel。兩種圖的整塊高度相同，換角度時下面不會動。
- 角度點的底部在選項 panel 上方 8px。
- **專屬簽名與騎乘配備的角度由頁面決定，不讓使用者選**：專屬簽名固定放大上車架（簽名的位置）；騎乘配備的清單是全車側面，選到哪個配件就聚焦哪個部位（車把、把手帶、龍頭看座艙，飛輪看後輪，鏈條、大盤看傳動）。這兩處不顯示角度點，滑動、鍵盤都不換角度（桌機同樣）。

### 客製車：購物車抽屜（≤ 767）

### 客製車：分享視窗

## 13. 檢查方式

1. **字級與顏色**：改完字級或新增區塊後，用 Chrome 量一次，同層級元素 `getComputedStyle` 的 `font-size`／`line-height`／`color` 要一樣；1440、1280、1024、768、375 都要看。
2. **跨寬度一致**：在 1024、768、375 量同一元件的 `border-radius`、`font-weight`，要相同（第 10 節列出的排列變化除外）。客製車的 `font-size` 也要相同。
3. **點擊區**：375px 掃一次每個 `button`、`a`、`input` 的高度，或它 `::before` 的高度，對照原則 3。
4. **共用元件**：各頁的 header、footer 逐項比對 computed style，只允許外層 margin 不同。
5. **快取**：改了 `header.js`、`cart.js`、`mobile-rwd.css`、`stage-preview.js`，要更新引用處的 `?v=`。`cart.js` 也由 `header.js` 自動載入，那裡的版本號要一起改。

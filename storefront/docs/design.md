# Storefront 設計規範

給所有在 `storefront/`、`customized.html` 上改畫面的人。新增區塊前先對一下這份，避免同一層級的字、間距、陰影各做各的。
（`storefront/scenario-2/` 是 Ginny 的頁面，不在這份規範的修改範圍內。）

最後更新：2026-10-24

---

## 1. 字級階層

中文字筆畫密，同樣 px 看起來比英文小，所以下限比一般英文網站高一點。

| 層級 | 用在哪裡 | 桌機 | 手機 | 字重 | 行高 | 顏色 |
|---|---|---|---|---|---|---|
| 頁面主視覺標題 H1 | 首頁 hero、客製介紹頁 hero、列表頁 hero | 44–66px | 34–52px | 600–800 | 1.1 | 依背景 |
| 主視覺副標 | hero 標題下的一兩行 | 16px | 16px | 400 | 1.85 | `#4A5563`（淺底）／白 88%（深底） |
| 橫幅標題 | 壓在照片或卡片上的大標（首頁「這段路，你想怎麼騎？」、「台灣登山車越野基地」、客製頁 CTA） | 36–40px | 28–32px | 800 | 1.2 | 依背景 |
| **區塊標題 H2** | 一般內容區塊（Explore Your Ride、六大零件規格、規格亮點…） | **30px** | 26–30px | **800** | 1.2 | `#141A22` |
| **區塊說明** | 區塊標題正下方的一兩行小字 | **15px** | **15px** | 400 | **1.75** | **`#4A5563`**，與標題間距 **10px** |
| 卡片標題 | 車款卡、商品卡 | 20–24px | 18–20px | 700–900 | 1.3 | `#141A22` |
| 內文 | 段落、說明、對話內容 | 15px（最少 14px） | 14–15px | 400 | 1.7–1.75 | `#4A5563` |
| 次要資訊 | 地址、日期、規格補充、表單標籤 | 13–14px | 13–14px | 400–600 | 1.6 | `#4A5563`／`#7A8492` |
| 標籤／膠囊 | 「建議」「NEW」「先備這件」、篩選 chip | 12–13px | 12–13px | 600–700 | 1 | 依底色 |
| 法律小字 | 頁尾隱私權、版權 | 12px | 12px | 400 | 1.6 | `#7A8492` |

**下限**：中文字不小於 12px；會被閱讀的說明文字不小於 14px（次要資訊可到 13px）。英文數字的小標（例如 `01`、`SADDLE · 3/4`）可以到 11–12px，但要加字距。

### 區塊標題＋說明的寫法（已在全站統一）

```css
h2 { font-size: 30px; font-weight: 800; }
h2 + p { margin-top: 10px; font-size: 15px; line-height: 1.75; color: #4A5563; }
```

2026-10-24 檢查並統一的地方：首頁 Explore／Featured（間距 6→10px）、首頁橫幅說明（14→15px）、首頁 hero 副標（14.5→16px）、客製介紹頁五個區塊（六大零件 14→15px、塗裝區顏色）、商品頁（標題 34px/700→30px/800、說明 16→15px）、結果頁（標題 28→30px、說明 14.5→15px）、客製頁頂部說明（14→15px）。

主視覺副標統一 16px（首頁、客製介紹頁、列表頁、試騎、結果頁）。商品頁的副標會跟著視窗縮放，見「已知問題」。

### 返回與麵包屑

依頁面類型分兩種，外觀規則相同：

| 頁面類型 | 用法 | 例子 |
|---|---|---|
| 內容頁（列表、商品、介紹頁） | 麵包屑 `首頁 / 分類 / 目前頁` | 礫石列表頁、商品頁 |
| 有步驟的流程（客製頁、試騎問卷） | `‹ 返回 上一步` | 選車系頁「返回客製化介紹」、選車款頁「返回車系」、設定頁「返回車款選擇」 |

- 位置：header 下方左上角，對齊頁面左邊界。
- 字：14px、字重 500、`#4A5563`，滑過變 `#141A22`。
- 麵包屑：分隔線 `/` 用 `#9AA4B0`；目前頁 `#141A22`、字重 600。每一項不在字中間換行（`white-space:nowrap`），放不下時整項換到下一行。
- 深色照片上：連結 `rgba(255,255,255,.72)`、分隔線 `.45`、目前頁白色。

## 2. 中文斷行

不要讓一個字或半個詞單獨掉到下一行（例如「染」、「分層／遮罩」、「RRS 及／DCF」）。

- **先改寬度或字數**，讓它一行放得下。
- 放不下時，**用片語包住、整段換行**：把後半句包在 `display:inline-block` 的 span 裡，放得下就同一行，放不下就整段掉到下一行。
  ```html
  <p>選擇你的車系，探索特製樣板與經典塗裝，<span class="nb">打造專屬於你的騎乘風格。</span></p>
  ```
  ```css
  .nb { display: inline-block; }
  ```
- `text-wrap: balance` 會在詞中間切開，中文不要用；`text-wrap: pretty` 可以當輔助，但不能取代上面的做法。

## 4. 間距

- 頁面左右留白：`var(--shell)` 置中，1440 寬時左右各 36px；手機 16px。
- 區塊上下：88–96px。
- 標題 → 說明：10px。說明 → 內容：24–40px。

## 5. 陰影

### 單車去背圖的陰影（商品頁、客製介紹頁塗裝區）

兩層：整台車的柔和落影＋兩個輪胎各一團接地陰影。只用 drop-shadow 會像浮在空中。

```css
.bike img { filter: drop-shadow(0 18px 24px rgba(20,26,34,.16)); }
.bike::after {           /* 接地陰影，放在車子底緣 */
  content:""; position:absolute; left:0; right:0; bottom:-5%; height:10%; z-index:-1; filter:blur(3px);
  background:
    radial-gradient(closest-side, rgba(20,26,34,.30), rgba(20,26,34,.12) 50%, transparent) 4.85% 50% / 34% 100% no-repeat,
    radial-gradient(closest-side, rgba(20,26,34,.30), rgba(20,26,34,.12) 50%, transparent) 94.7% 50% / 34% 100% no-repeat;
}
```

- 先量出輪胎著地點（車子去背框寬度的百分比）。目前 15 張塗裝樣板都在 **20.2%／79.5%**。
- **注意**：`background-position` 的百分比不是橢圓中心。寬 W% 的橢圓要讓中心落在 C%，位置要寫 `(C − W/2) ÷ (100 − W) × 100%`。

### 卡片、浮層

`0 1px 2px rgba(20,26,34,.06), 0 6px 18px rgba(20,26,34,.08)`；聚焦或浮起時加深到 `0 2px 4px …/.05, 0 14px 32px …/.11`。

## 6. 動態

- 一般轉場 0.25–0.6 秒，`cubic-bezier(.16,1,.3,1)`。
- **切換內容用小幅位移＋淡化**（約 20px），不要整個畫面寬度飛入飛出。方向跟著選單方向。
- 同一組內換圖（例如換樣板）：0.25 秒交叉淡化。
- 聚焦某個物件時，其他物件淡到 50%。
- 一定要處理 `prefers-reduced-motion`：直接換、不位移。

---

## 7. 鉛筆手繪風格（客製介紹頁「六大零件規格」）

- 顏色：鉛筆灰 `#8A9099`（線條）、速寫圖 `rgb(72,78,88)`。
- 有筆觸：顆粒濾鏡、淡淡重描一次、線條兩端略出頭；直線輔助線兩端漸層淡出，不要在半空突然斷掉。
- 速寫只在滑到／點選該零件時出現，一次一張；平常畫面只有車和製圖線。
- 背景小速寫不加文字。

## 8. 已知問題（尚未處理）

1. **首頁手機版版面壞掉**：390px 寬時 hero 文字跑到畫面右邊外面，看不到。
2. **共用 header 手機版重疊**：390px 寬時導覽文字與右側圖示重疊（公路／登山壓在搜尋、收藏圖示上）。
3. **商品頁字級會跟著視窗縮小**：`product.html` 用 `--u: max(100vw,1200px)/1672` 縮放所有字，1440 寬時「首頁」麵包屑、尺寸連結、分頁籤只有 10–12px，手機上更小（約 8.6px）。建議改成 `max(13px, calc(var(--u) * N))` 給下限。
4. 低於下限、之後要調的小字（2026-10-24 掃描）：
   - 結果頁日期膠囊「建議」10.5px、星期 11.25px；配件標籤「先備這件」11.5px。
   - 情境問卷「目前騎的」10.8px、選項副標 11.5px。
   - 商品頁「同車系車款」標籤 11px。
   - 首頁新聞卡說明 12.5px（屬內文，建議 14px）、Featured 卡片商品名 12.5px（建議 13.5px）。

## 9. 檢查方式

改完字級或新增區塊後，用 Chrome 量一次：同層級的元素 `getComputedStyle` 的 `font-size`／`line-height`／`color` 要一樣；1440、1280、390 三個寬度都要看。

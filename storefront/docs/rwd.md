# 客製車頁面 RWD 規範

適用：`storefront/custom-studio/index.html`（客製介紹頁）、`customized.html`（選車系 → 選車款 → 設定 → 確認），以及兩頁共用的 header、footer、購物車抽屜。
上層規範：[Storefront 設計規範](design.md)（字級、顏色、斷行）與「GIANT 客製車設計系統」artifact（CJnnaBhuW59YHNmU7muUYv）。這份只寫**螢幕變窄時的規則**；兩者衝突時以設計系統為準。

最後更新：2026-11-03。原本的 `storefront/custom-studio/Design.md`（舊版手機選單）已刪除，以這份為準。

---

## 1. 這兩頁在手機上要做到的事

使用者在手機上選一台車、一步步配到能加入購物車。畫面上永遠要看得到**現在在哪一步、車長什麼樣子、總價多少、下一步在哪**；其他東西都可以收起來，這四件不行。

## 2. 原則（每一條都能檢查）

1. **元件不因螢幕變窄而換長相。** 圓角按鈕在 375px 還是圓角、圓形社群圖示還是圓形、卡片圓角同一個數字。變窄只能改排列、間距、顯示與否，不能改元件本身的形狀、字重、顏色。
2. **字級只用設計系統的六級**：12／14／15／16／24／27。不為手機另訂一套字級；手機上的標題（購物車、panel 標題、分享視窗標題）一律 16px／700／1.4。
3. **能點的東西高度至少 40px。** 視覺比 40 小的控制項（色票、圓點、文字連結）加一個看不見、置中的 40px 點擊區（`::before`）；被 `clip-path` 裁切而加不了點擊區的（置頂的返回列），本體直接長到 40px。
4. **同一個 panel 裡的同類選項等高、平均分欄寬。** 兩個並排選項用 `repeat(2, minmax(0,1fr))`，不讓其中一個因字多而變高。
5. **中文不斷在詞中間。** 照 design.md §2，用 `.nb`（inline-block）把後半句包起來；手機上不行就改字數，不用 `text-wrap:balance`。
6. **置頂的東西在捲動時不跳動。** 返回列、標題、panel 標題以 `position:sticky` 疊在 header 下面，高度寫成變數，JS 量的高度與 CSS 一致。

## 3. 斷點

| 寬度 | 用途 | 邊界 |
|---|---|---|
| ≤ 1023px | 設定頁改成單欄捲動（預覽在上、選項在下、總價列固定底部）；平板與手機共用 | 不要在這裡改 header／footer |
| ≤ 900px | header 換成手機版（漢堡選單、愛心收進會員選單）；footer 改單欄 | 兩頁同一套，由 `header.js` 的 `data-mobile-nav` 開啟 |
| ≤ 767px | 手機專屬：panel-head 併入步驟、預覽滑動換角度、點擊區規則、置頂返回列 | 大部分手機規則都放這裡 |
| ≤ 370px | 只縮 logo（72px）與 header 圖示間距 | 不再收功能、不縮點擊區 |

## 4. Tokens（數值 → 用途 → 邊界）

**間距**
- `16px` — 手機頁面左右留白、panel 內距、header 內圖示到邊。所有手機頁面都用這個值，不要另用 20 或 24。
- `28px` — 桌機 panel 內距（設計系統）；購物車抽屜用變數 `--gc-pad` 在兩個值之間切換，不在各元素上寫死。
- `8px` — 「緊貼」：步驟列到返回、角度點／背景按鈕到選項面板的距離。
- `6px` — 卡片內文字群組的 gap（例如變速套件卡 `gs-body`）。

**圓角**（每個寬度都相同）
- 按鈕 8（「下一步」例外：永遠是膠囊形）、卡片 10、說明卡 12、購物車浮層 14、panel 18。手機上的選項面板頂端 14px 圓角、底部 0。
- 圓形的東西（社群圖示、角度點、背景色票、會員頭像）永遠是 50%／999px。

**高度**
- header 64px，不隨寬度變。
- 點擊區最小 40px（見原則 3）。可以更大（選單列 48px），不能更小。
- 設定頁置頂列：`--cfg-nav: 40px`（返回列）＋ `--cfg-title: 28px`（標題）。改了高度要同步改這兩個變數。

**顏色** 照 design.md §3，手機沒有額外顏色。強調色只有一個，選取狀態用 `--navy` 外框，不換底色。

## 5. 字級在手機上的用法

| 用在哪 | 字級 | 邊界 |
|---|---|---|
| 頁面主標（選車系、選車款） | 24px | 只有一個 |
| panel 標題、購物車標題、分享視窗標題、總價數字 | 16px／700 | 不放大成 h2 的桌機尺寸 |
| 選項名稱、選單列、子選單 | 16px／600 | 子選單跟主選單同級，不縮小 |
| 內文、說明（`gs-desc`、`gs-full`、分享資訊列） | 14px，行高 1.4–1.5 | 同一張卡的上下兩段字級必須一樣 |
| 群組標籤（精品配件分類）、價格標籤 | 14px／400 `#4A5563`、12px | 標籤不用粗體 |

圖片裡的字（設計卡 canvas）不受 CSS 控制，會跟著圖縮小。畫在 1200px 寬的圖上時，車名 48px、規格 34px，才不會在視窗裡縮到看不清楚。

## 6. 元件決策

**Header（≤ 900）**
- 左：漢堡（40×40，開啟後變 ✕）；中：logo 80px；右：搜尋、購物車、會員、選車顧問。
- 我的最愛（愛心）不在 header 上，收進會員選單的「我的最愛」那一列，點了打開同一個抽屜。
- 漢堡選單：從 header 下緣到畫面底部滿版、白底、不透明；不放搜尋與會員（header 上已有）；**列與列之間沒有分隔線**（參考 Aesop）。
- 子選單一律**換頁**（右滑進、左滑回），每頁第一列是「‹ 返回」；有分類主圖的放 16:9 圖卡（`gn-kv`）。精品配件頁照 Apple 的寫法：灰色 14px 分類名，下面列項目。
- 切換只用 transform／opacity，0.5s `cubic-bezier(.16,1,.3,1)`；目前所在頁不換色（「客製化」不變藍）。

**Footer（≤ 900）**：單欄，每個連結一列、高 40px；社群圖示維持圓形；logo 跟 header 同為 80px。兩頁的 footer 必須逐項一致。

**選車系／選車款（≤ 767）**
- `pick-page` 上方 64px（header 高）；返回列置頂在 header 下方，跟 header 之間**沒有線**，背景與頁面同色、滿版（`box-shadow:0 0 0 100vmax` ＋ `clip-path`）。
- 返回列 `padding:0 0 12px`；頁面主標 `margin:16px 0 24px`。兩頁一致。

**設定頁（≤ 767）**
- 由上到下：返回列與標題（置頂，往下捲時一起收起）→ 車圖預覽 → 選項 panel → 底部固定的總價＋「下一步」。
- 步驟列併進 panel-head（`cfgPlaceIntro()` 把 `.intro` 搬進 `#panelHeader`），跟返回之間 8px；目前步驟名稱跟 panel 標題重複時，標題只留給螢幕閱讀器（`.step-dup`）。
- 步驟圓圈都有灰色外框，目前這步是深色外框。
- panel-head 內距 `16px 16px 0`；設定頁返回連結 margin、padding 都是 0，高度靠 `min-height:40px`。
- **「下一步」按鈕在手機與平板只寫「下一步」**，不寫下一步的名稱；最後一步是「加入購物車」，編輯時是「更新購物車」，從確認頁回來是「儲存並返回確認」。
- 漆面選項放在「漆面」標題下一行，兩個選項平均分欄寬。
- 配件選項卡：加價金額是圖片右上角的白色膠囊（12px）；不加價的不顯示標籤，也不留空位。

**車圖預覽（≤ 767）**
- 換角度用**左右滑**；角度點只是位置指示，點了沒反應，平常隱藏，滑動後出現 1.5 秒。
- 背景切換是右下角一顆圓形色票（目前背景），點了往上展開其他選項，選好或點別處收起。
- 角度點與背景色票的底部都在選項 panel 上方 8px。
- **專屬簽名鎖定放大的上車架（簽名的位置），騎乘配備鎖定全車側面**：不顯示角度點，滑動、鍵盤、點配件都不換角度（桌機同樣）。

**返回連結**：14px／500／`#4A5563`。箭頭的尖端要跟下方標題左緣對齊（`.chev{margin-left:-5px}`），且跟文字垂直置中——置頂列用 `align-items:flex-end` 的地方，箭頭要再往上 2.5px。

**購物車抽屜（≤ 767）**：內距 16px；標題與合計 16px／700；商品價格移到品名下方靠左；數量按鈕 40×40；勾選框外加 40px 點擊區。

**分享視窗**：資訊列（塗裝／尺寸／總價）同為 14px、列之間沒有分隔線，只保留整組上方一條；間距收緊到 375×812 不用捲動就看得完。

## 7. 不要做的事

1. 不要因為螢幕變窄就把圓角改成方角、把圓形改成方形、把膠囊按鈕改成 8px 圓角。
2. 不要為手機另訂一套字級；新加的文字從設計系統的六級裡挑。
3. 不要讓任何可點的東西低於 40px，也不要為了塞下更多圖示去縮點擊區——空間不夠就收進選單。
4. 不要在手機選單裡加分隔線、加目前頁的藍色，也不要用展開收合取代換頁。
5. 不要在 header 與置頂的返回列之間留線或陰影。
6. 不要在手機上恢復「點角度點換圖」或常駐的整條角度＋背景工具列。
7. 不要讓專屬簽名、騎乘配備頁的預覽換到鎖定以外的角度。
8. 不要只改 `customized.html` 或只改客製介紹頁的 header／footer——兩頁要一起改，共用的部分改在 `storefront/js/header.js`、`footer.js`、`cart.js`。

## 8. 改完怎麼檢查

1. 在 1024、768、375 三個寬度量同一元件的 `border-radius`、`font-size`、`font-weight`，三個寬度要相同（第 6 節列出的排列變化除外）。
2. 375px 掃一次點擊區：每個 `button`、`a`、`input` 的高度，或它 `::before` 的高度，要 ≥ 40px。
3. 兩頁的 header、footer 逐項比對 computed style，只允許外層 margin 不同。
4. 改了 `header.js`、`cart.js`、`mobile-rwd.css`、`stage-preview.js`，要更新引用處的 `?v=`。

底部列：不用「選這個配色」的四種做法

整個客製頁的規則是「點卡片就是選取」，所以底部列平常放資訊或留白，只有選到的卡片才變成編輯入口。都是實際頁面，可以點其他 Type 試。

甲色票列移到底部列

每張卡底部都是「上／下／Logo」色票列，上方一條細線。選到的卡片，底部列變淡灰底、右邊一支鉛筆，整列都能點。沒選的卡片也有內容，不會空一塊。

乙價格移到底部列

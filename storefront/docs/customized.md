## 1. 手機上要做到的事

使用者在手機上選一台車、一步步配到能加入購物車。畫面上永遠要看得到**現在在哪一步、車長什麼樣子、總價多少、下一步在哪**；其他東西都可以收起來，這四件不行。

只用 **12／14／15／16／24／27**，桌機手機相同，不另訂手機字級；新加的文字從這六級裡挑。

| 用在哪 | 字級 | 邊界 |

## 4. 間距、圓角、高度

**間距**
- 桌機 panel 內距 28px（設計系統），手機 16px。
- `8px` 是「緊貼」：步驟列到返回、角度點到選項面板。
- `6px` 是卡片內文字群組的 gap（例如變速套件卡 `gs-body`）。

**圓角**（每個寬度都相同）
- 一般按鈕 8、卡片 10、說明卡 12、購物車浮層 14、panel 18。
- 手機上的選項面板頂端 14px 圓角、底部 0。
- 圓形的東西（角度點、背景色票）永遠是 50%。
- 「下一步／加入購物車」是膠囊形（999px）；**這條和設計系統的 8px 不一致，見第 9 節**。

**高度**
- 「下一步」按鈕：手機（≤ 767）最小 44px，平板以上 48px。
- 設定頁置頂列：`--cfg-nav: 40px`（返回列）＋ `--cfg-title: 48px`（車名 24px＋下方目前顏色一行 20px＋下方留 4px）。改了高度要同步改這兩個變數，JS 量的高度也要一致。

## 5. 選車系／選車款（≤ 767）

- `pick-page` 上方 64px（header 高）；返回列置頂在 header 下方，跟 header 之間**沒有線或陰影**，背景與頁面同色、滿版（`box-shadow:0 0 0 100vmax` ＋ `clip-path`）。
- 返回列 `padding:0 0 12px`；頁面主標 `margin:16px 0 24px`。兩頁一致。

## 6. 設定頁

### 版面（≤ 767）

- 由上到下：返回列與標題（置頂，往下捲時一起收起）→ 車圖預覽 → 選項 panel → 底部固定的總價＋「下一步」。
- 步驟列併進 panel-head（`cfgPlaceIntro()` 把 `.intro` 搬進 `#panelHeader`），跟返回之間 8px；目前步驟名稱跟 panel 標題重複時，標題只留給螢幕閱讀器（`.step-dup`）。
- 步驟圓圈都有灰色外框，目前這步是深色外框。
- panel-head 內距 `16px 16px 0`；設定頁返回連結 margin、padding 都是 0，高度靠 `min-height:40px`。
- 漆面選項放在「漆面」標題下一行，兩個選項平均分欄寬。
- 切換步驟一律回到頁面頂端，面板位置固定，不因步驟不同而跳動。

### 「下一步」（所有寬度）

- 按鈕寫出下一站名稱，例如「下一步：專屬簽名」。最後一步是「加入購物車」，編輯時是「更新購物車」，從確認頁回來是「儲存並返回確認」。
- 依序走完目前步驟的每一站，不跳過：變速套件 → 車架尺寸 → 特仕塗裝 → 自由配色 → 專屬簽名 → 騎乘配備 → 升級加購 → 確認配置。

### 塗裝（所有寬度）

- 切換塗裝的 tab 或按「下一步」只是換看選項，車圖、選項狀態和價格都不變。使用者點了某個選項才算選定，車圖和價格才跟著改。
- 還沒選自由配色時，自由配色的塗裝方式、漆面、顏色都不預設選取；同理，已選自由配色時，特仕塗裝的卡片也不顯示選取。
- 名稱下方顯示目前選定的顏色，格式一律是「類型・顏色」，例如「特仕塗裝・Sand Storm」、「自由配色・鈷藍」。
- 塗裝方式卡片寫含基本價的完整金額（單色、分色 + NT$ 3,380，漸層 + NT$ 6,380），不另外寫基本價與小計。

### 配件選項卡（所有寬度）

- 加價金額是圖片右上角的白色膠囊（12px）；不加價的不顯示標籤，也不留空位。
- 配件圖統一放在標籤下方的同一塊區域（距上 36px、左右 16px、距下 12px），不論有沒有加價，大小都一樣，價格不能壓到圖；卡片比例固定 1.25，不被圖撐高。

## 7. 車圖預覽

### 手機（≤ 767）

- 換角度用**左右滑**；角度點只是位置指示，點了沒反應，平常隱藏，滑動後出現 1.5 秒。
- 背景切換是步驟列最右邊一顆 32px 圓形色票（目前背景），點一下直接換下一個背景（淺色 → 深色 → 山路），不展開選單。平板以上維持工具列裡的色票。
- 全車圖上下各留 16px；放大的局部圖上方 16px、下方貼齊選項 panel。兩種圖的整塊高度相同，換角度時下面不會動。
- 角度點的底部在選項 panel 上方 8px。

### 所有寬度

- **專屬簽名與騎乘配備的角度由頁面決定，不讓使用者選**：專屬簽名固定放大上車架（簽名的位置）；騎乘配備的清單是全車側面，選到哪個配件就聚焦哪個部位（車把、把手帶、龍頭看座艙，飛輪看後輪，鏈條、大盤看傳動）。這兩處不顯示角度點，滑動、鍵盤都不換角度。

## 10. 檢查方式

1. **字級**：在 1024、768、375 量同一元件的 `font-size`、`font-weight`、`border-radius`，三個寬度要相同（第 4、6、7 節列出的排列與高度變化除外）。新加的字級只能是六級之一。
2. **點擊區**：375px 掃一次每個 `button`、`a`、`input` 的高度，或它 `::before` 的高度，要 ≥ 40px。
3. **「下一步」流程**：從變速套件一路按到確認配置，每一站都要經過；在自由配色只切 tab 不點選項，總價不能變。
4. **快取**：改了 `assets/stage-preview.js`、`storefront/js/header.js`、`cart.js`、`custom-advisor.js`，要更新引用處的 `?v=`。

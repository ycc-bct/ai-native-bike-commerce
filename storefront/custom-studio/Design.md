# Mobile Header 與 Footer 設計規範

更新日期：2026-11-02  
適用頁面：客製車 Landing Page（`storefront/custom-studio/index.html`）

本文件記錄目前客製頁的 Mobile Header、Footer 設計與實作規則，供後續頁面沿用。共用導覽內容仍由全站 Header／Footer 提供；這些手機版覆寫目前只套用於客製頁，並非已修改所有頁面。全站基礎規範另見 [Storefront 設計規範](../docs/design.md) 與 [Header 說明](../docs/header.md)。尺寸皆為 CSS px，不是 pt。

## 1. 響應式範圍

| 畫面寬度 | Header | Footer |
| --- | --- | --- |
| 大於 900px | 維持桌機導覽 | 維持桌機多欄 |
| 371–900px | Hamburger、Logo、功能圖示 | 單欄、每項一列 |
| 370px 以下 | 搜尋與會員移入選單；保留其他功能圖示 | 同樣單欄，文字可自然換行 |

不得為容納更多圖示而縮小點擊區域。窄螢幕透過收納功能解決空間不足。

## 2. Mobile Header

### 版型與尺寸

Header 固定於頂端，高度 64px。排列由左至右為 Hamburger、GIANT Logo、右側功能區。桌機文字導覽在 Mobile 隱藏，由選單提供相同導覽內容。

| 元素 | 規格 |
| --- | --- |
| Hamburger 點擊區 | 44 × 44px，左側 8px、頂部 10px |
| Hamburger 圖示 | 24 × 24px，置中於點擊區 |
| Logo | 左側起點 56px，寬度 80px，高度依原始比例 |
| 右側功能區 | 距右側 8px，項目之間 4px |
| 功能按鈕點擊區 | 每個 44 × 44px，不壓縮 |
| 一般功能圖示 | 22 × 22px；AI 助理保留品牌圖示樣式 |
| 鍵盤焦點 | 可見藍色外框 `#1F4FE0`，2px，外距 2px |

右側功能沿用共用 Header 的順序與動作。370px 以下隱藏頂端的搜尋及會員入口，但選單內仍須提供。Header 顏色與捲動狀態沿用共用樣式；選單展開後使用不透明淺色底，確保文字清楚。

### 展開選單

| 元素 | 規格 |
| --- | --- |
| 位置 | 緊接 Header 下方，距頂 64px，左右滿寬 |
| 內距 | 上下 16px、左右 24px |
| 背景／文字 | `#F3F5F7`／`#141A22` |
| 高度 | 最高 `calc(100svh - 64px)`，內容過長時內部捲動 |
| 主選單連結 | 16px，每列最小高度 48px |
| 分隔線 | 1px `#DCE1E7` |
| 子分類 | 使用可展開的分類，子連結縮排 16px |
| 陰影 | `0 12px 20px #0002` |

互動規則：

- 點 Hamburger 展開／收合，更新 `aria-expanded`，按鈕名稱對應「開啟主選單」或「關閉主選單」。
- 按鈕以 `aria-controls="studio-mobile-menu"` 指向選單；選單具有「手機主選單」名稱。
- 點選導覽連結後關閉選單；點 Header 外側亦關閉。
- 按 Escape 關閉已展開的選單，焦點回到 Hamburger。
- 分類使用原生 `details`／`summary`，可用鍵盤操作。
- 搜尋與會員入口呼叫原有功能，避免維護兩套功能邏輯。

## 3. Mobile Footer

### 內容順序

所有區塊由上往下排列，所有連結每項獨立一列：

1. GIANT Logo 與品牌標語。
2. 車款分類與連結。
3. 精品配件分類與連結。
4. 探索分類與連結。
5. 支援分類與連結。
6. 訂閱最新消息與 Email 欄位。
7. Instagram、Facebook、YouTube，各自一列，圖示旁顯示平台名稱。
8. 版權資訊。
9. 隱私權政策、使用條款、Cookie 設定，各自一列。
10. 地區與語言。

訂閱輸入框與送出按鈕是一組表單控制，保持同一列。Footer 不強制一屏高度，內容隨頁面自然捲動。

### 版型與尺寸

| 元素 | 規格 |
| --- | --- |
| 背景 | 白色，頂部沿用共用分隔線 |
| 內容寬度 | `calc(100% - 32px)`，置中，左右各 16px |
| 主內容上下內距 | 36px |
| 分類區塊間距 | 28px |
| 分類與訂閱標題 | 16px，粗體，下方間距 8px |
| 一般連結 | 14px，最小列高 44px，垂直置中 |
| 訂閱表單 | 高度 48px，送出按鈕寬度 48px |
| 社群連結 | 14px，最小列高 44px；圖文間距 12px，列間距 8px |
| 底部資訊區 | 垂直排列、靠左，區塊間距 12px，行高 1.6 |
| 法律連結 | 14px，最小列高 44px，每項一列 |
| 地區與語言 | 獨立一列，不使用桌機左側分隔線及縮排 |

文字、邊框與圖示的基礎色彩沿用共用 Footer 的 `--ink`、`--ink-70`、`--ink-50`、`--line`。版權與品牌標語等輔助文字沿用共用樣式；不要將所有文字都設為分類標題大小。

## 4. 實作來源與維護方式

| 檔案 | 負責內容 |
| --- | --- |
| [index.html](index.html) | 載入共用元件與頁面覆寫 |
| [mobile-rwd.css](css/mobile-rwd.css) | Mobile 點擊尺寸、選單、Footer 單欄版型 |
| [layout-fixes.js](js/layout-fixes.js) | Hamburger 建立、導覽複用、選單開關與鍵盤操作；同檔另含塗裝圓弧定位 |
| [refinements.css](css/refinements.css) | Mobile Header 基礎高度、圖示尺寸等既有版型 |
| [共用 footer.js](../js/footer.js) | Footer 分類、連結、訂閱與社群標記 |
| [共用 footer.css](../css/footer.css) | Footer 桌機結構、基礎視覺 |

Mobile 覆寫使用 `#siteHeader`／`#siteFooter` 限定範圍，並在基礎樣式之後載入。新增分類或修改網址時，應修改共用資料來源，不要另寫一份手機專用連結清單。移植到其他頁面時，只抽取 Header／Footer 相關規則與導覽程式，不要一併帶入客製頁的塗裝或零件互動。

目前共用 Footer 部分連結為 `#`，訂閱表單尚未提交資料；這份規範定義呈現與操作尺寸，不代表這些功能已接上服務。

## 5. 驗收清單

以下為後續修改時的驗收項目，不代表本次已逐項完成瀏覽器測試。

- 在 320、375、390、600、900px 寬度檢查：Logo、Hamburger 和功能區不重疊、沒有橫向捲動。
- 在 370／371px 檢查搜尋及會員的收納切換；在 900／901px 檢查手機與桌機版型切換。
- 所有 Header 功能按鈕至少 44 × 44px；選單每列至少 48px。
- Hamburger 可開關，分類可展開，導覽後關閉，Escape 可關閉並回復焦點。
- Footer 分類、社群、法律連結均一項一列；訂閱欄位不超出畫面。
- 長文字自然換行；放大文字後不與其他連結重疊。
- 使用 Tab 鍵可辨識目前焦點；圖示按鈕有可讀名稱。
- 桌機 Header／Footer 不受到 Mobile 規則影響。
